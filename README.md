# Cube Solver

A static 2×2 Rubik’s Cube solver with animated turns and diagnostics for impossible layouts.

## Test locally

Open `index.html` in a browser. Select **Try an example** to run a seven-move solve and **Replay turn** to watch a move again. Select **Try a twisted-corner example** to check the diagnostics.

## Work in Codex and Antigravity

Clone this repository and open its folder in Antigravity. In Codex, select the same GitHub repository or open the local checkout. Use separate branches and checkouts if both tools are editing at the same time. Review the changes in a pull request before merging.

## Deployment

This site requires no build step. GitHub is used for source control and review. Publish to Netlify separately after testing.
